# Components

| Component | Files | What it does | Used in |
|---|---|---|---|
| Button | `css/base.css` (`.btn`, `.btn-primary`, `.btn-secondary`) | Pill-shaped link or button with a fixed size. `.btn-primary`: transparent with a white border. `.btn-secondary`: white background with purple text. Both turn purple on hover. | Hero, product categories, featured products, footer |
| Icon sprite | `assets/icons/sprite.svg` | SVG symbols: `icon-logo`, `icon-user`, `icon-help`, `icon-bag`, `icon-facebook`, `icon-instagram`, `icon-whatsapp`, `icon-menu` (not used yet). | Header, footer |
| Header | `css/components/header.css` (`.site-header`) | Fixed bar with the logo and two navigation lists. | `index.html` |
| Hero | `css/components/hero.css` (`.site-hero`) | Banner with a background image, subtitle, `h1` and two buttons. | `index.html` |
| Category card | `css/components/product-category.css` (`.category-card`, `.category-card-link`, `.overlay`, `.category-btn`) | Image link with a dark overlay and a button-style label. | `index.html` (product categories) |
| Featured product card | `css/components/featured-products.css` (`.card`) | Rounded card with a background image, placed in the grid by area name. | `index.html` (featured products) |
| Footer | `css/components/footer.css` (`.site-footer`) | Newsletter field, social links, four link lists and the copyright line. | `index.html` |
