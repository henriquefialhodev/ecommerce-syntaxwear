# Features

The site has one page, `index.html` (home). All links point to `#`. There is no JavaScript.

## Header
- Fixed near the top and centred, with a white background, rounded corners and a shadow. It stays visible while scrolling.
- Logo from the sprite, linking to the home page.
- Centre navigation: Masculino, Feminino, Outlet.
- Right navigation: Nossas lojas, Sobre, and icon links for account, help and bag.
- CSS: `css/components/header.css`.

## Hero
- Banner with the background image `banners/hero.jpg` and rounded corners.
- Subtitle "Krypton One", the page `h1` and two buttons: "Ver modelos" (`.btn-primary`) and "Comprar" (`.btn-secondary`).
- CSS: `css/components/hero.css`.

## Product categories
- Four category cards (casual, sport, modern, futuristic). Each card is a link with a background image, a dark overlay and a button-style label.
- CSS: `css/components/product-category.css`.

## Featured products
- CSS grid with named areas: 4 columns and 3 rows of 300px.
- One highlight card with a subtitle, a title and two buttons (Feminino, Masculino), plus five image cards.
- Product images are CSS backgrounds.
- CSS: `css/components/featured-products.css`.

## Footer
- Newsletter: email field with a label and a "Subscrever" button. The field is not inside a form, so nothing is submitted.
- Social links: Facebook, Instagram and WhatsApp, with icons from the sprite.
- Four link lists: Masculino, Feminino, Outlet and Sobre.
- Copyright line.
- CSS: `css/components/footer.css`.
